# Chat → GitHub Issue → Codex → Pull Request 演示

这是独立的纯文档演示项目，用于验证已确认的 Chat 讨论如何通过 GitHub Issue 交给 Codex，并将草稿 Pull Request 返回 Chat 审阅。

项目不包含量化策略、交易程序、账户数据或生产配置。禁止真实交易、部署、读取或写入密钥、上传敏感信息，以及自动合并 Pull Request。

初始仓库仅包含本说明和 `AGENTS.md`。演示 Issue 将驱动后续独立分支新增任务模板及交接文档；创建 Issue 本身不代表 Codex 已启动，所有未验证的连接环节须如实标注。
